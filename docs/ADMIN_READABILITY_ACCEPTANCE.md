# 管理员只读排查与可读性更新

- /admin 与 /admin.html 均由服务端认证和 SITE_ADMIN_EMAIL 配置保护；缺省拒绝。
- API 每次独立检查管理员身份，不接受客户端 role/isAdmin 标志。
- 支持工作区/项目总数、25 条分页、按用户 ID 精确筛选、记录原因后读取项目详情、最近 100 条访问记录。
- 项目本身只读；查看操作仅写 admin_reads 审计表。审计写入失败时不返回项目数据。
- 站点登录页、账号说明和首页页脚说明管理员读取用途；数据库仍为 Sites 托管的 D1。
- 管理员配置使用站点 get_site 返回的 owner 邮箱，不将邮箱或配置值放进静态资产。
- 24 项自动化测试通过；涵盖普通用户拒绝、匿名拒绝、伪造客户端角色无效、管理员查询、审计记录、只读性、失败关闭和原有账户隔离。
- 浏览器实测状态入口标题 18px、正文 16px；936px 高度窗口中该区域高 856px，无横向溢出，点击卡片仍打开对应阶段创建表单。
- 此次浏览器未以真实生产管理员账号读取用户数据；生产权限绑定与数据显示需所有者登录后确认。
- 没有提供批量导出、用户项目编辑/删除或权限管理入口。
