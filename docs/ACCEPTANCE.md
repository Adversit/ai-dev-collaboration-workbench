## v1.1 新增验收记录

| 设计要求 | 实现证据 |
|---|---|
| 两层模块视图 | `parentId` + `moduleLevel=container/leaf`；示例包含报道接入、事件处理、结果输出三类大模块 |
| 折叠与展开 | 大模块默认可折叠，展开后显示小模块；展开状态保存在项目数据中 |
| 关系投影 | 折叠时按真实起点、终点和关系类型汇总；展开时显示内部真实端点；汇总关系可查看明细 |

| 验收前置 | 模块支持正常、边界、异常、回归验收项；通过必须有实际结果与证据 |
| 复验与人工接受 | 修改预期后自动回到未验证并保留历史；人工接受单独记录残余风险说明 |

| 数据兼容 | 旧 schema 2 项目可加载；示例项目自动补充分层结构；不根据名称猜测普通项目分组 |

## 已由实现与自动化测试覆盖

| 设计要求 | 实现证据 |
|---|---|
| 中文默认、可切换英文 | `dist/locale.js`、顶部/侧栏语言按钮、`localStorage` 语言偏好 |
| 首页层级与三项初始动作 | 首页只有“开始项目”为主按钮，方法与示例为次级入口 |
| 工作阶段可跳转而非强制瀑布 | 方法地图九阶段可直接进入，并显示“可跳转、回退与并行” |
| 项目状态持久化 | `adc-projects-v2` 本地存储、保存状态提示、JSON 导入/导出 |
| 空间画布与节点关系 | 默认展示数据流；可拖动节点、20px 网格吸附、重叠避让、数据/执行/依赖三种连线；节点状态由标签表示 |
| 三级语义缩放 | `far` / `normal` / `near`；缩放同时改变节点信息层级 |
| 节点聚焦与详情 | 选中后相关节点/连线高亮，其余淡出；右侧面板可调整宽度、全页阅读 |
| 结果优先 | 详情顺序为产物 → 摘要与状态 → 验证证据 → 相关产物 → 方法依据 |
| 模块卡与验证 | 模块保存校验 WHY/WHAT/INTENT；样例固定输入运行 3 项断言 |
| 无模型 API | 源码仅使用浏览器 API；首页明确说明推理留在 Agent |
| WebMCP | 特性检测并注册 `read_methodology`、`get_module_template`、`save_module_card`、`read_release`、`get_verification_plan` 与只读项目状态工具 |
| 响应式与减少动态效果 | 移动端减少侧栏/面板，`prefers-reduced-motion` 和设置项均关闭动画 |
